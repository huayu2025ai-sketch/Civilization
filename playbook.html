实战手册 · BUILD ORDER & DECISIONS

把每个回合，变成优势

这里不讲抽象的“努力发展”，而是按回合拆解生产顺序、城市分工、战争窗口和胜利转型。

01 · STANDARD OPENING

标准开局：前 50 回合

适合多数文明的稳定模板，领袖特色明显时再做替换。

TURN 01—08

侦察兵

找部落村庄、城邦、自然奇观与邻国。首都优先考虑水源、高产地块和可规划区域的位置。

TURN 08—18

投石兵 / 战士

处理野蛮人营地，争取“杀蛮族弓箭手”等尤里卡。看到邻国军力后再决定是否转军事路线。

TURN 18—32

开拓者

第二城应尽早落地，优先占水源、战略资源、海岸枢纽或高邻接区域，不必追求完美地块。

TURN 30—50

工人 + 第一个区域

改良能立即增产的地块；锁定学院、圣地、商业中心或军营的位置，再补纪念碑和区域建筑。

02 · WIN CONDITION

四条主线的执行顺序

先选择赢法，再让城市、政策和伟人服务主线。

SCIENCE

科技胜利

学院 → 商业中心 → 工业区 → 太空港。优先研究写作、教育、工业化，后期把生产力集中到太空项目。

检查：科技值 / 生产力 / 大科学家 / 战争安全
CULTURE

文化胜利

剧院广场 → 博物馆 → 机场。收藏艺术品、考古文物和摇滚乐队，开放边界并经营旅游倍率。

检查：文化值 / 伟人作品 / 国际旅游 / 遗产
DOMINATION

统治胜利

军营 → 兵种升级 → 军团/军队 → 攻城。集中打穿一个方向，攻下首都后及时议和、补给和转场。

检查：军力差 / 战略资源 / 金币 / 战线长度
FAITH

宗教胜利

圣地 → 伟大先知 → 使徒。先建立宗教优势，再用有升级的使徒开传播走廊，保护圣城免受反传教。

检查：信仰值 / 宗教压力 / 使徒升级 / 圣城防守

03 · FIELD NOTES

关键决策速查

什么时候扩张？

首都能稳定生产开拓者、第二城有安全落点时就扩张。不要为了一座边境城市牺牲军力和忠诚度。

什么时候开战？

有明确目标、可升级的老兵、足够金币和战略资源时开战。没有攻城手段时，不要在城墙下消耗。

政策卡怎么换？

生产阶段使用单位/开拓者加速卡；区域阶段切区域卡；战争阶段切军队维护和单位生产卡；和平期及时换回经济卡。

每 10 回合检查

宜居度、住房、忠诚度、贸易路线、邻国军力、战略资源、伟人竞争和下一时代的尤里卡/鼓舞。
