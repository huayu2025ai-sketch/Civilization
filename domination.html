完整攻略 · DOMINATION PLAYBOOK

统治胜利，
从第一支军队开始

这是一条可以照着执行的路线：先用经济和科技造出时代优势，再用集中兵力拆掉一个方向，拿下首都后及时补给、议和、转场。

先看总图

你的胜利循环

不要把统治胜利理解成
“一直生产兵然后冲城”。

1 · 找目标侦察邻国、资源、城防和首都方向。
2 · 造优势用军营、科技、政策和工业区压低生产成本。
3 · 打穿一线集中远程、近战和攻城单位，不要分散战线。
4 · 吃下成果占首都、拿资源、修复战线，再决定下一个目标。

01 · 开局

回合 1—40：准备第一次战争

目标：不是马上开战，
而是让战争值得开始。

生产顺序

侦察兵 → 战士/投石兵 → 开拓者 → 军事单位

先开视野确认邻国，再补一支远程或近战。首都生产开拓者前，确保野蛮人不会从侧面打断。

检查：至少 2 座城市、2—3 支战斗单位、一个明确目标。
科技优先

采矿 → 弓箭 → 青铜器 → 铁器 / 骑术

没有铁就走骑术或远程线；有铁且邻国近，铁器能把老兵战士升级为剑士。不要为了直冲铁器而忽略弓箭防守。

检查：战略资源已显示，且至少一种主力兵种可以生产。
市政优先

法典 → 工艺 → 对外贸易 → 军事传统 → 政治哲学

生产单位时使用单位加速卡，准备铺城时切扩张卡。政治哲学后根据局势选寡头政府，获得更强的早期军事弹性。

检查：政策槽没有空着，升级前已准备金币。

02 · 城市与建筑

哪些城市建什么？

军队数量的上限，
最终由城市分工决定。

首都 · 生产核心军营 → 兵营/马厩 → 军械库 → 军事学院

负责连续生产主力单位和军团。若工业区邻接高，优先补工业区、工坊和工厂。

第二城 · 经济与补给商业中心 → 市场 → 银行；或港口 → 灯塔 → 海港

负责金币、贸易路线和单位升级费用。不要让所有城市都只造兵，经济断掉战争就会停。

第三城 · 工业支援工业区 → 工坊 → 工厂 → 发电厂

放在能覆盖多座城市的位置。它不一定要靠近前线，但要让核心城市更快生产攻城器械和现代单位。

前线城 · 只补必要建筑城墙 → 纪念碑/粮仓 → 军营或商业中心

前线城市先活下来、能修复、能补给，不要在敌方边境浪费时间建完整建筑链。

03 · 兵种编组

一支能攻城的军队长什么样？

前排

近战 / 重骑兵

承受伤害、保护远程、最后占领城市。没有近战单位，打掉城防也无法完成占领。

输出

弓箭手 / 弩手 / 炮

站在安全距离输出。优先升级老兵，避免把高经验单位送到城防或敌方骑兵面前。

破城

攻城塔 / 破城槌 / 投石车

敌城有城墙时才带上。攻城器械需要近战护卫和侦察，不能单独推进。

机动

骑兵 / 轻骑兵

绕后、掠夺、切断贸易和追击残兵。不要让骑兵正面撞城墙，把它当作改变战线的工具。

推荐基础编组：2 近战 + 2 远程 + 1 攻城/支援 + 1 侦察；面对首都再按城防增加攻城器械。每推进 3—5 回合检查伤势、补给和撤退路线。

04 · 开战与占领

什么时候可以按下“宣战”？

可以开战

目标明确；主力兵种领先一个时代或有数量优势；有攻城手段；有足够金币升级；首都与前线之间能持续补给。

先别开战

敌人有城墙而你没有攻城；战略资源还没改良；军队分散在两条战线；经济只能维持几回合；自己城市的忠诚度正在下降。

占城后先做三件事

留下近战单位驻防，修复城防与忠诚度，派工人连接资源。不要刚占城就继续冲下一座，先让战线恢复生产。

何时议和

目标首都已拿下、敌方关键资源已夺取、战线过长或战争疲劳开始拖累城市时议和。统治胜利不要求每座城市都立刻吞并。

05 · 中后期转型

从剑士一路滚到现代军队

每次升级都要问：
它能否缩短下一场战争？

古典

目标：用剑士、弓箭手或骑手打穿一个邻国。
重点：铁器/骑术、军营、寡头、升级老兵。

中世纪

目标：弩手 + 骑士 + 攻城器械拆城。
重点：机械、学徒制、雇佣兵、封建主义。

文艺复兴

目标：火枪手、炮兵和军团结束第二条战线。
重点：火药、工业区、民族主义、动员。

现代

目标：坦克、飞机、炮兵或核武器快速结束。
重点：工业化、炼钢、内燃机、飞行、核裂变。

每 10 回合问自己

其他路线 · 可执行攻略

四套胜利路线简表

先按自己的地图和领袖选择，
再进入对应的生产循环。

SCIENCE · 科技

把产出转成太空项目

开局：侦察兵 → 开拓者 → 学院；第二城优先高邻接学院。

科技：写作 → 教育 → 学徒制 → 工业化 → 火箭学。

市政：政治哲学 → 启蒙运动 → 城市化 → 太空竞赛。

建筑：学院、工业区、商业中心，最后在高生产城市建太空港。

检查：科技领先但项目慢，说明工业区、工厂、贸易路线还没补齐。

CULTURE · 文化

让外国游客超过竞争者

开局：保证扩张和防守，尽早规划剧院广场，不要过早把所有生产投入奇观。

科技：写作 → 货币 → 印刷术 → 飞行；优先解锁博物馆和机场。

市政：戏剧与诗歌 → 人文主义 → 自然史 → 大众传媒。

建筑：剧院广场、博物馆、机场；作品要主题化，边界要开放。

检查：文化值高但旅游低，优先补作品、考古、开放边界和旅游倍率。

RELIGION · 宗教

先稳圣城，再开传播走廊

开局：圣地 → 神社 → 先知；只有能稳定获得伟大先知时才全力走宗教。

科技：占星术 → 砌砖 → 教育；重点是圣地防守和使徒支援，而非盲目铺圣地。

市政：神秘主义 → 神学 → 改革教会；政策卡优先信仰与宗教单位。

单位：使徒负责神学战斗和建立走廊，传教士负责扩散，僧侣或护卫保护关键城市。

检查：敌方反传教压力高时，先清理敌方宗教单位，再继续传播。

DIPLOMACY · 外交

用支持、城邦和援助取胜

开局：侦察城邦并完成任务，保留金币和外交支持，不要把所有资源换成短期产出。

科技：货币 → 教育 → 电力；商业中心、港口和生产力保证援助能力。

市政：政治哲学 → 外交服务 → 全球化；政策槽要服务使者、间谍和外交支持。

建筑：商业中心、港口、政府区、外交区；间谍优先监听竞争者和保护关键区域。

检查：世界议会前观察票数，关键回合用外交支持阻止领先者拿分。

通用攻略 · 临场判断

三种局面怎么救？

科技落后，但军力领先

不要停战等科技。用现有兵种拿资源、赔款或首都，战争收益可以补经济；同时研究能直接升级主力的科技。

城市很多，但生产很慢

停止复制区域，挑两座核心城建工业区和工厂；其它城市只补纪念碑、商业中心或军事单位。

邻国太近，发展被打断

先做防守军、城墙和外交交易，选择一个可快速夺取的目标，避免同时与两家文明开战。

路线选错了

不要整局重来。保留现有城市和军队，把生产转向最接近完成的目标：科技补工业，文化补旅游，统治补攻城，宗教补使徒。
